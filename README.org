* Description
:PROPERTIES:
:ID:       280135a0-2cff-4e93-8679-7d1a6d56b7b2
:END:

YAMS installs and configures a complete media server stack using Docker containers:

Download Management:
- [[https://www.qbittorrent.org/][qBittorrent]] - Torrent client
- [[https://sabnzbd.org/][SABnzbd]] - Usenet downloader
- [[https://github.com/qdm12/gluetun][Gluetun]] - VPN client for secure downloads

Media Management:
- [[https://sonarr.tv/][Sonarr]] - TV show management and automation
- [[https://radarr.video/][Radarr]] - Movie management and automation
- [[https://lidarr.audio][Lidarr]] - Music management and automation
- [[https://www.bazarr.media/][Bazarr]] - Automatic subtitle management
- [[https://prowlarr.com/][Prowlarr]] - Indexer management for your \*arr apps

Media Servers (Choose One):
- [[https://jellyfin.org/][Jellyfin]] (Recommended) - Open source media server
- [[https://emby.media/][Emby]] - Media server with premium features
- [[https://www.plex.tv/][Plex]] - Popular media server with advanced features

Management & Monitoring:
- [[https://www.portainer.io/][Portainer]] - Container management UI
- [[https://containrrr.dev/watchtower/][Watchtower]] - Automatic container updates

* Features
:PROPERTIES:
:ID:       0e072c32-3158-4961-869c-49920090f3d5
:END:

YAMS provides a comprehensive media server solution with:

- *Smart Media Management*: Automatically organizes your media library
  - Downloads new episodes and movies as they become available
  - Categorizes content into appropriate folders
  - Manages music and book collections
  - Fetches subtitles in your preferred languages

- *Flexible Media Access*: Access your content anywhere
  - Web interface for browser-based streaming
  - Apps for mobile devices (iOS/Android)
  - Smart TV apps
  - Roku, Apple TV, and other streaming devices
  - Transcoding for optimal playback on any device

- *Security and Privacy*
  - Built-in VPN support for secure downloads
  - User management and sharing controls
  - SSL/TLS encryption support

- *Easy Management*
  - Simple CLI interface with `yams` command
  - Web-based management through Portainer
  - Automatic container updates via Watchtower
  - Backup and restore functionality

* Before Installation
:PROPERTIES:
:ID:       1c609bfc-4e6e-4fd8-8129-1b722fd7cda8
:END:

Prepare the following:

1. *Installation Location*
   - Default: ~/opt/yams~
   - Ensure your user has write permissions

2. *Media Directory*
   - Default: ~/srv/media~
   - Will contain subdirectories:
     + ~/srv/media/tvshows~: TV series
     + ~/srv/media/movies~: Movies
     + ~/srv/media/music~: Music files
     + ~/srv/media/books~: Books and audiobooks
     + ~/srv/media/downloads~: Temporary download location
     + ~/srv/media/blackhole~: Watch folder for torrents

3. *Non-root User*
   - Regular system user to own and manage files
   - Must have sudo privileges for initial setup

4. *VPN Service* (Optional but Recommended)
   - Supported providers listed at [[https://yams.media/advanced/vpn#official-supported-vpns][yams.media/advanced/vpn]]
   - [[https://protonvpn.com/][ProtonVPN]] recommended for:
     + Simple configuration
     + Port forwarding

* Usage
:PROPERTIES:
:ID:       9e995141-b386-4962-9842-7209bedc5651
:END:

YAMS provides a simple CLI interface:

#+begin_src
yams - Yet Another Media Server

Usage: yams [command] [options]

Commands:
--help                    displays this help message
restart                   restarts yams services
stop                      stops all yams services
start                     starts yams services
destroy                   destroy yams services so you can start from scratch
check-vpn                 checks if the VPN is working as expected
backup                    backs up yams to the destination location

Examples:
  yams start              # Start all YAMS services
  yams backup /path/to/backup  # Backup YAMS to specified directory
#+end_src

* Custom Additions
:PROPERTIES:
:ID:       f1a3c9e5-7d2b-4e89-a45f-8c9f1e3d5a67
:END:

This fork of YAMS includes the following custom enhancements:

** Hardware Acceleration Support
:PROPERTIES:
:ID:       a8b2f4c6-9e1d-4f78-b32c-7a5e8d9c2f41
:END:

Added comprehensive GPU hardware acceleration support for media transcoding:

- *Interactive Configuration*: Installation script now prompts users to enable/disable hardware acceleration
- *Automatic Setup*: When enabled, automatically configures Docker containers with:
  + Device access to ~/dev/dri~ for GPU hardware
  + Proper group permissions for ~render~ (993) and ~video~ (44) groups
  + Hardware acceleration device mapping in Docker Compose

- *Benefits*:
  + Significantly improved transcoding performance
  + Reduced CPU usage during media conversion
  + Better streaming experience for multiple users

- *Compatibility*: Supports Intel/ATI/AMD graphics hardware with proper drivers

** Configurable Timezone Support
:PROPERTIES:
:ID:       c7d9e2f8-4a6b-4c89-9f3e-1b8d5a7c3e92
:END:

Enhanced timezone configuration for better scheduling and logging:

- *Interactive Setup*: Installation prompts for user's timezone instead of hardcoded default
- *Flexible Input*: Accepts standard timezone formats (e.g., ~America/New_York~, ~Europe/London~)
- *Environment Integration*: Timezone is properly configured across all containers via ~TIMEZONE~ environment variable
- *Default Fallback*: Defaults to ~America/New_York~ if no timezone is specified

- *Benefits*:
  + Accurate scheduling for automated downloads
  + Correct timestamps in logs and interfaces
  + Proper date/time display in media server interfaces

** Technical Implementation
:PROPERTIES:
:ID:       b4f6c8e1-3a7d-4e92-8f5c-9d2a6b4e7f83
:END:

These custom additions are implemented through:

- *Enhanced Installation Script* (~install.sh~):
  + Added ~configure_timezone()~ function
  + Added hardware acceleration prompts and configuration
  + Extended Docker Compose template processing

- *Modified Docker Compose Template* (~docker-compose.example.yaml~):
  + Added hardware acceleration device and group placeholders
  + Replaced hardcoded timezone with ~${TIMEZONE}~ variable

- *Extended Environment Configuration* (~.env.example~):
  + Added ~TIMEZONE~ environment variable support

These modifications maintain full compatibility with the original YAMS functionality while adding enhanced configuration options for improved performance and user experience.

** Additional Media Services
:PROPERTIES:
:ID:       e5f7c2a9-6b4d-4e81-9c3f-2a8e5b9d1c74
:END:

The custom Docker Compose configuration (~docker-compose.custom.yaml~) includes additional specialized media services:

*** Audiobookshelf
:PROPERTIES:
:ID:       d4c8f1e3-7a9b-4f56-8e2d-5c9a7b3f6e81
:END:

A self-hosted audiobook and podcast server for managing audio content:

- *Container*: ~advplyr/audiobookshelf:2.28.0~
- *Access*: http://localhost:13378
- *Features*:
  + Audiobook library management and streaming
  + Podcast subscription and playback
  + Progress tracking across devices
  + User management and sharing
  + Mobile app support
- *Storage*:
  + Configuration: ~${INSTALL_DIRECTORY}/config/audiobookshelf/~
  + Media library: ~${MEDIA_DIRECTORY}/audiobooks/~
  + Metadata: Separate metadata storage for library information

*** Calibre-Web
:PROPERTIES:
:ID:       a7b3e9f2-4c6d-4e85-9a1f-8b5c2d7e4a93
:END:

A web-based eBook library management system built on Calibre:

- *Container*: ~lscr.io/linuxserver/calibre-web:0.6.25~
- *Access*: http://localhost:8083
- *Features*:
  + Web-based eBook reader and library browser
  + Support for multiple eBook formats (EPUB, PDF, MOBI, etc.)
  + User management with reading progress tracking
  + Send-to-Kindle functionality
  + OPDS catalog support for eReader integration
  + Search and filtering capabilities
- *Storage*:
  + Configuration: ~${INSTALL_DIRECTORY}/config/calibre-web/~
  + eBook library: ~${MEDIA_DIRECTORY}/books/~
- *Integration*:
  + Uses timezone configuration from main YAMS setup
  + Follows YAMS user permission model (PUID/PGID)
  + Optional Calibre converter support via Docker mods

These additional services extend YAMS beyond traditional video/audio content to provide a complete digital media ecosystem including audiobooks and eBooks, making it a comprehensive self-hosted media solution.
